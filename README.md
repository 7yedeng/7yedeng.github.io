## 到账、发码、核销、权益要分别确认

1. **到账确认**：回原订单看付款状态。“我已付款”按钮只请求复查，截图本身不是发货确认。
2. **卡密交付**：自动发码商品需要付款确认且有库存；人工预订按商品承诺等待。保存订单号和查单方式。
3. **卡密核销**：按交付说明前往[自助充值网站](https://qianyeit.com/#redeem)，核对目标账号后提交兑换。
4. **会员权益**：等待处理结果，再到目标账号官方套餐页查看实际方案和到期时间。

收到卡密不等于会员已开通。处理中或结果不明时先查原单、原码记录，避免重复提交或再次购买。
