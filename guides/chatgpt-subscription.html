1. 选择商品：先看用途，再看规格

ChatGPT 系列订阅用于自己的符合条件账号，不是购买共享账号。网页会员、API 余额与额外点数属于不同商品，购买其中一种不代表同时获得其他权益。

商品当前交付说明购买前重点核对
ChatGPT Plus · 1个月付款确认且有可交付库存后自动发码目标账号资格、现有订阅、商品条件
ChatGPT Pro 100 · 1个月按商品页的实际库存与交付说明对应 Pro 规格、新购或升级条件
ChatGPT Pro 200 · 1个月按商品页的实际库存与交付说明与其他 Pro 商品的实际差异
ChatGPT Pro 500 · 1个月 · 预订人工预订交付服务时段、累计发货时限与超时处理

价格、库存、可办理范围可能变化，以下单时的商品页为准。官方模型能力、用量和到期信息以目标账号及服务商当前规则为准，不从商品名称推定固定额度。

2. 付款前检查目标账号

  • 确认准备办理的是自己的正确账号，能正常登录，并查看官方套餐页显示的现有订阅。
  • 按 Shop 当前办理规则，已有 Apple／Google 渠道订阅不办理直接升级；有官方 0 元会员历史的账号不适用。现有订阅、升级差价、特殊低价历史或资格不清时，先联系支持。
  • 商城购买邮箱用于订单联系与查询，不会自动决定充值到哪个 ChatGPT 账号。购买账号与目标订阅账号不要混淆。
  • 目标账号仍须符合服务商支持地区、条款和订阅要求。付款完成不会改变这些条件。

商城下单不要求提交目标账号登录凭据。兑换时只按指定核销页面提供必要资料；不要在公开评论、仓库 Issue 或截图中展示密码、验证码、完整卡密、会话凭据或查单密码。

3. Shop 与微信／支付宝合作渠道分别查单

在 Shop 购买

进入 Anagnoraxis Shop 选择商品，按当前收银台可用方式付款。使用 USDT 时，逐项核对网络、币种、地址、精确金额和截止时间，转出手续费另计，确保净到账金额符合订单要求。

需要微信／支付宝

前往 16688 合作店铺，以该店铺当前展示的支付方式和商品为准。该平台处理它自己的收款、订单与交付记录；在 16688 付款，不会自动把 Shop 的另一个订单改成已付款。

从哪个渠道下单，就先回到哪个渠道查看订单与联系对应支持。不要为了同步订单状态，在两个渠道重复付款。

4. 分别确认到账、发码、核销与会员权益

  1. 到账确认：回到原订单查看付款状态。点击“我已付款”只是请求复查，转账截图也不能单独证明订单已经完成核对。
  2. 卡密交付：自动发码商品在付款确认且有可交付库存后领取卡密；人工预订商品按页面时限等待处理。保存订单号与查询方式。
  3. 提交核销：按交付说明进入 自助充值网站，核对目标账号，填写兑换码与页面要求的必要资料。
  4. 确认权益：等待核销结果，再到目标账号官方套餐页查看实际方案和到期时间。收到卡密、提交请求与会员生效是不同步骤。

若正在处理或结果不明，先查原订单和原码记录，再联系支持；不要连续重复提交或重新购买同一项服务。

5. 发货后30天内兑换，不等于会员从下单日开始

按当前销售规则，卡密从成功发货起30天内可成功兑换一次。逾期转人工核查，不自动删除客户订单；建议收到后及时兑换。

卡密兑换窗口与会员周期分别计算。商品标注“1个月”时，实际生效和到期时间以目标账号显示为准，不从下单日直接推算，也不把多次购买视为一定可以叠加。

需要续费或换档时，先核对当前套餐、到期时间和原订阅渠道。商城发码不代表官方自动续费已经取消；如需管理后续扣款，应到实际官方订阅渠道处理。

6. Pro 500 预订按5个服务小时累计

Pro 500 当前采用预订后人工交付，每单限1份。收款确认后，在累计5个服务小时内发货；服务时段为每日北京时间09:00—23:59，非服务时段暂停，次日09:00继续累计。

例如22:00确认收款，最迟约次日12:01；02:00确认收款，从当日09:00起算，最迟约14:00。具体处理以订单与当前商品说明为准。

超过累计5个服务小时仍未发货，可以联系支持申请取消未履约部分；人工核实未发货后退款。这个流程与会员已经充值成功后申请官方退款分开处理。

7. 付款或兑换异常时，先停止重复操作

转账了，但订单还未确认

核对是否已广播并在所选网络确认，再检查网络、币种、净到账金额、地址和时限。保留原订单号与交易哈希，联系支持核查。

少付、多付、拆分支付或订单超时

不要继续补转猜测金额，也不要沿用旧收银台地址和金额。取消或超时不会撤销链上转账，这些异常需要核对原交易，不能保证自动合并、退款或追回。

卡密不能用，或兑换后权益还没变化

先确认是否为对应商品的码、是否已经兑换、目标账号是否正确；保存脱敏错误信息与原记录。核销结果未知时不反复重试，不把一次提示失败直接当作未扣款或未处理。

8. 售后按实际交付与退款结果处理

未收到卡密、卡密不可用、充值失败或结果不明，提供购买渠道、订单号和脱敏问题说明，由支持核对付款与交付状态。不要在公开区域贴完整兑换码或账号资料。

已完成充值后如需向订阅服务商申请退款，按其官方流程提交。官方批准、退款到账和商家结算是不同阶段；不承诺官方必定批准或固定比例返还。

实际收到官方退款后，按实际收到的退款净额结算，并逐项明示可核实的实际费用及换算依据，不重复扣费。未履约预订取消与成功订阅后的官方退款分别核查。

完整规则见 Shop 服务与退款条款，资料处理说明见 隐私说明。

常见问题

Plus、Pro 与 API／Codex 余额是一回事吗？

不是。它们是不同商品和计费用途；按实际所需选择，不能认为买了会员就同时获得所有 API 或额外余额。

收到卡密就代表会员开通了吗？

不代表。还要完成兑换，并到正确目标账号核对官方权益。

所有订单最低都要5 USDT吗？

不能统一这样理解。交易所可能设最低提现额和手续费，订单则有自己的应付金额；分别以所用平台和当前收银台要求为准。

有问题应该联系哪里？

先回到实际下单渠道。Shop 订单可通过 联系支持页 找到当前人工服务入口；客服服务时段为每日北京时间09:00—23:59。

Anagnoraxis 是 OpenAI 官方网站吗？

不是。Anagnoraxis Shop 提供独立的商品与售后服务。服务商的账号政策、官方方案与权益仍以其当前规则和账号实际状态为准。
