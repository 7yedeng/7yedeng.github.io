02 / HOW I BUILD

先把问题说清楚，再写页面。

界面可以简单，工作顺序要完整。下面是我采用的建站检查顺序，具体实现随项目需要调整。

  1. 01

    明确需求

    谁来使用，要解决什么问题，希望对方完成哪个动作。给每个页面指定一个主要任务。

  2. 02

    核对事实

    整理自己的资料与可追溯来源，区分已确认、推测与未知。价格、能力和承诺有依据再写。

  3. 03

    组织内容

    先确定页面层级、稳定网址与下一步链接，再安排标题、说明、步骤和必要的限制。

  4. 04

    做出可读版本

    先让主要文字和链接直接出现在 HTML 中；按真实需求增加交互，检查手机、键盘和加载失败时的表现。

  5. 05

    验证与发布

    核对功能、权限、输入、限流和回退。公开页面与私有接口分别验收，发布后读回实际版本。

  6. 06

    持续维护

    保持正文、标题、canonical、站图与实际状态一致；提交更新后，再观察抓取、索引和真实使用反馈。

WORKING NOTE

记录做到了哪一步。
